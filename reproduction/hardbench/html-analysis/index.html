Trigger 不是一个独立的二分类问题

105 条生成记录显示：memory invocation 的效用非单调、依赖调用历史；当前候选器还会在同一原子计算内部重复触发，产生可定位的高阶干扰。

CURRENT VERDICT

当前证据不支持直接训练“逐候选、独立 invoke / skip”的 vanilla Trigger。

更合理的目标是：只在语义完整的推理边界上，由带调用历史、预算和 verifier 信号的顺序控制器决定 HOLD / INVOKE / STOP。

06 · Decision

复现已经完成它最重要的任务：把问题定位清楚

现阶段最有价值的不是给当前 Trigger 扩数据，而是先消除候选器制造的伪决策，并确认 Weaver 是否真的提供可救分支。

证据支持什么

位置有因果作用

单点会显著改变 completion，多点会出现不可由单点预测的交互。

效用依赖历史

{2}、{3} 安全，{2,3} 有害。

候选质量是瓶颈

同一原子运算内部连续触发，制造不必要的高阶干扰。

Prompt 与 inference 是两层控制

部分错误在任何 inference invoke 发生前已经出现。

证据尚不支持什么

× 独立二分类当前候选 utility 非独立
× 距离型标签会把错误抵消标成正例
× Prompt 永远开启0063 已给出反例
× 调用次数代理同次数可得到相反结果
× 直接声称总体效果n = 10，只适合机制发现
07 · Next experiment

Gate Sanitation v1

用一个小而信息密度高的实验，先回答“过滤后是否存在稳定、可验证的 exact-positive signal”。只有答案为是，才进入 Trigger 训练。

STEP 01
清洗候选边界

过滤 calculator span、小数和金额逗号内部候选；同一语义 step 最多调用一次。

输出：filtered candidate manifest
STEP 02
补全 prompt-only N

在原始 10 题上全部运行，分离 prompt augmentation 与 inference invocation。

输出：完整 prompt 因果对照
STEP 03
同 manifest 六条件配对

比较 A、S、N、original always、filtered always、random50。

输出：paired net gain
STEP 04
只对剩余错误题重跑 sweep

记录 exact-positive 覆盖率、N 正题被破坏率、最小破坏交互率。

输出：可训练性判断
GATE
决定训练 Trigger 还是回头改 Weaver

若过滤后仍几乎没有 exact-positive 分支，问题在 memory 内容/目标，而不在时机分类器。

Appendix

口径、限制与可审计来源

指标口径

以 semantic exact 为主指标。Base 与风格控制有数值正确但未使用 \boxed{} 的回答，若采用官方格式评分，A/S 会分别从 3/10、4/10 降到 2/10、1/10，混淆模型能力与格式遵循。

核心限制
  • 试点仅 10 题，不能做显著性或总体泛化结论。
  • 单点穷举集中在 3 道代表题；交互真值表集中在 0710。
  • 当前数据足以否定若干过强假设，但还不足以估计清洗后的最终收益。
