07 · Decision

不是“训练或不训练”，而是先按可救性分流

0810 给出了真正的 Trigger utility 正标签；其他样本则说明，无正例的题应回流给 Weaver / Prompt，而不是强行给 gate 背锅。

证据支持什么

存在干净 Trigger 正例

0810 的第一位 bit 完全切分错/对，且发布版 gate 可复现。

正例可承受后续调用

固定首位 invoke 后，16/16 个五步分支都保持 310。

效用依赖历史

1088 的 011xx 有害，111xx 却被早期调用保护。

Prompt 与 inference 是两层控制

0063 在任何 inference invoke 前已经从正确变错。

证据尚不支持什么

× 所有失败都归 Trigger7/8 完整失败样本三步 oracle 无正例
× 独立二分类当前候选 utility 依赖历史
× 距离型标签会把错误抵消标成正例
× Prompt 永远开启0063 已给出反例
× 调用次数代理同次数可得到相反结果
× 直接声称总体效果n = 10，只适合机制发现

Appendix

口径、限制与可审计来源

指标口径

以 semantic exact 为主指标。Base 与风格控制有数值正确但未使用 \boxed{} 的回答，若采用官方格式评分，A/S 会分别从 3/10、4/10 降到 2/10、1/10，混淆模型能力与格式遵循。

核心限制
  • 试点仅 10 题，不能做显著性或总体泛化结论。
  • 三步 oracle 覆盖全部 8 个完整 prompt-only 失败样本；五步只扩展 5 个高信息量样本。
  • 五步实验临时把最大 inference augmentation 从 checkpoint 原生 3 提高到 5，权重未变。
  • 当前数据足以做样本级判责，但仍不足以估计大规模总体收益。
